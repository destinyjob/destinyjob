# Destiny Job

Software developer. I build native Android apps in Kotlin, React and Next.js front-ends in TypeScript, and the Node.js APIs and release infrastructure behind them.

Most of my work lives in private repositories, so here is what I have shipped.

## Products

| Project | Platform | Reach |
| --- | --- | --- |
| **LinkDrop** | Android TV, Firestick | 400,000+ users |
| **TVWiz** | Android TV, Firestick | 400,000+ users |
| **Browsy** | Android | 40,000+ downloads |
| **TVPal** | Android TV, Firestick | Accepted into the Amazon Appstore |
| **JustCoffee** | Web, Android | Subscription commerce platform |

**LinkDrop** is an app store for Android TV and Firestick. I build and maintain the whole stack: the Kotlin TV app, a Next.js web front-end, a Node.js/Express and MongoDB backend, and the signed-URL distribution and nginx hosting that serves releases.

**TVWiz** takes a new Android TV device from factory state to a configured home screen, installing the user's chosen apps for them.

**TVPal** runs a full device checkup across network, DNS, storage, memory and VPN, pinpoints what is causing buffering and applies the fix. Ships as separate Play and Amazon builds.

**JustCoffee** is a subscription commerce platform: one REST API serving a Next.js storefront, an internal admin dashboard and a native Android client, with Stripe and PayPal billing built so a repeated payment webhook can never double-charge a customer.
